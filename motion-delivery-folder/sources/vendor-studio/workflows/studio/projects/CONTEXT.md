# Film log

## PURPOSE
One folder per film. Pointers only. The work stays in the stage that made it.

## ENTER_WHEN
You need to see where a film's files are, or read `production.json`.

## PROCESS
Open `<id>/CONTEXT.md`. Then open the stage `npm run status -- <id>` names. Do not read every film.

## OUTPUTS
`production.json` is written by the CLI. Approvals live there, not in a stage file.

## BOUNDARIES
Do not copy stage instructions into this log. Do not open `_archive/`; it holds superseded pipeline docs, not current instructions.
