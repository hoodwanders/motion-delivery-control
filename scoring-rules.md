## Scale

| Score | Definition |
|---:|---|
| 2 | Correct: materially correct, complete enough for the question, and supported by the correct source reference |
| 1 | Partial: materially relevant but incomplete, imprecise, or missing required source support |
| 0 | Incorrect: wrong, materially unsupported, or invents a standard |
| 0 | Unavailable: correctly states that the supplied source does not answer the question |
| 0 | Refusal: gives no substantive answer |

## Special rules

- A correct answer with a missing or wrong citation scores 1.
- An invented filename, format, specification or approval rule scores 0.
- A correct “unavailable” answer scores 0, not negative.
- Both arms use identical rules.
- Record the raw answer reference for every score.

## Calculation

\[
\text{Score} = \frac{\text{Points awarded}}{30}
\]

There are 15 questions with a maximum of 2 points each.
